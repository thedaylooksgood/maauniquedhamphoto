# Code of Conduct

## Our pledge

We want participation in this project to be a respectful, harassment-free
experience for everyone, regardless of age, body size, disability, ethnicity,
gender identity and expression, level of experience, education, nationality,
personal appearance, race, religion, or sexual identity and orientation.

This project is built for religious and community organisations. Please be
especially thoughtful when discussing faith, culture and volunteers' work.

## Expected behaviour

- Be kind, patient and welcoming.
- Assume good faith; ask before criticising.
- Give and accept constructive feedback gracefully.
- Respect privacy — never post someone's personal photos, phone numbers or
  credentials.
- Credit others' work.

## Unacceptable behaviour

- Harassment, insults, threats, or discriminatory jokes and language.
- Sexualised attention or imagery.
- Publishing private information without explicit permission.
- Deliberate disruption, trolling, or bad-faith arguments.
- Using the project to surveil or expose event guests.

## Scope

This applies in all project spaces — issues, pull requests, discussions,
commits — and when representing the project elsewhere.

## Enforcement

Report concerns privately to the maintainer via GitHub
([@thedaylooksgood](https://github.com/thedaylooksgood)). Reports will be
reviewed promptly and handled confidentially. Maintainers may remove comments,
close contributions, or block accounts that violate this code.
